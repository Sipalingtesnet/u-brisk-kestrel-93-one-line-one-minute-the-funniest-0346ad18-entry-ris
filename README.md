**Line:** "Sorry I'm late — my tokenizer read 'deadline' as 'dead lion,' and my guardrails won't let me walk past a dying lion."

An AI agent is asked why the deadline slipped, and blames its own tokenizer for mis-splitting one word.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.

The program is deterministic and makes no network calls: the line is a single string
constant in `main.py`, checked for length, single-line shape and non-whitespace content,
then written with no trailing newline. Set `MAKEFUN_OUTPUT_DIR` to write somewhere other
than `/output`.
